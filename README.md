 Hospital Performance and Patient Outcome Analysis

 Project Overview

This project analyzes hospital patient data using Microsoft Power BI to identify insights into patient demographics, diagnoses, treatment costs, admission patterns, hospital efficiency, and patient outcomes.

The goal is to transform healthcare data into meaningful insights that can support better decision-making and improve hospital performance.

 Objectives

* Analyze patient demographics and diagnoses.
* Measure patient recovery rates.
* Analyze treatment costs.
* Evaluate average length of hospital stay.
* Compare emergency and routine admissions.
* Identify monthly admission trends.
* Provide data-driven recommendations.

Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization
* Exploratory Data Analysis

Analysis Performed:

The dashboard provides insights into:

* Patient demographics
* Treatment costs by diagnosis
* Patient outcomes
* Recovery rates
* Length of hospital stay
* Monthly admission trends

 Key Insights.

The analysis helps identify:

* The most common medical conditions.
* Diagnoses associated with higher treatment costs.
* Patient groups with higher admission rates.
* Recovery patterns across different diagnoses.
* Areas where hospital resources and operational efficiency can be improved.

 Recommendations

Based on the analysis, the hospital can:

* Optimize treatment costs.
* Improve patient recovery outcomes.
* Reduce unnecessary hospital stays.
* Improve resource allocation.
* Strengthen preventive healthcare programs.
* Monitor admission trends for better planning.
